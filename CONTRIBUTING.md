# Contributing to Laravel Mosque Website CMS

Thank you for considering contributing.

## How to Contribute

1. Fork the repository and create your branch from `master`.
2. Make your changes with clear commit messages.
3. Make sure the application still installs cleanly: `composer install`, `npm install && npm run dev`, `php artisan migrate`.
4. Follow Laravel conventions and PSR-12.
5. Open a pull request describing what you changed and why.

## Reporting Bugs

Open an issue with steps to reproduce, expected and actual behavior, and your PHP / Laravel versions.

## Security Issues

Do not open public issues for security vulnerabilities. Email **sultanbayezidai@gmail.com** instead.

## Code of Conduct

Be respectful and constructive. Keep discussions focused on the code.
